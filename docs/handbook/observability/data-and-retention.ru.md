# Данные и сроки хранения

[English](data-and-retention.md) | [Оглавление справочника](../README.ru.md)

Что стек хранит, где, персональные ли это данные и как долго они живут.
Короткий ответ про сроки: **в репозитории не задан ни один срок хранения.**
Каждое хранилище работает на значениях по умолчанию своего upstream или
хранит данные, пока их кто-нибудь не удалит. Эта страница - инвентарь, с
которого стоит начинать, когда это придётся менять.

## Инвентарь

| Хранилище | Где | Содержимое | Персональные данные |
| --- | --- | --- | --- |
| Трейсы Langfuse | ClickHouse `langfuse-clickhouse` (20 Gi), Postgres `langfuse-db` (10 Gi), bucket MinIO `langfuse` (10 Gi) | полные промпты и ответы, модель, токены, задержка, имя пользователя, Keycloak `sub`, id PAT, id сессии | **да, включая содержимое разговоров** |
| Open WebUI | SQLite `webui.db` на PVC `openwebui-data` (5 Gi) | пользователи, чаты, файлы, объекты workspace, зашифрованные OAuth-токены | да, содержимое разговоров |
| Keycloak | Postgres `keycloak-db` (5 Gi) | учётные записи, роли, сессии, TOTP-секреты, если настроены | да |
| Токены pat-service | Postgres `pat-db`, таблица `personal_access_tokens` | HMAC-хэш, 15-символьный префикс, `sub` и имя владельца, даты, `issued_by` | да (идентификаторы) |
| Использование в pat-service | там же, таблица `qos_events` | строка на ответ чата или эмбеддингов: владелец, id сессии, модель, полоса, токены, стоимость, id токена | да (идентификаторы, без содержимого) |
| Valkey `envoy-ratelimit-valkey` | память, без персистентности | счётчики rate limit, цепочки сессий, окна расхода | идентификаторы, недолго |
| Prometheus (прикладной) | PVC `prometheus-data` (10 Gi) | метрики; метки `user` и `fairness_id` - это Keycloak `sub` | идентификаторы |
| Loki, Tempo, Prometheus из add-ons | namespace `monitoring`, чарт eg-addons | логи контейнеров, трейсы и метрики Envoy | в логах могут быть идентификаторы |
| Профили агентов | PVC `<runtime>-profile-<id>` в `agents` | сессии и история агентов, личные навыки, настройки | **да, содержимое разговоров** |
| Ключи агентов | Secret `agent-cred-<id>` в `agents` | текущий PAT агента пользователя | учётные данные |
| Лог запросов ninfer | `emptyDir` в поде ninfer | тайминги и число токенов по запросам | без содержимого; теряется при рестарте |
| repowise | собственный PVC на 20 Gi (`helm/repowise`) | проиндексированные публичные репозитории | нет |

## Сроки хранения сейчас

| Хранилище | Настройка в репозитории | Фактическое поведение |
| --- | --- | --- |
| Langfuse (ClickHouse, Postgres, MinIO) | нет | хранится, пока не удалят в Langfuse; ни TTL в ClickHouse, ни lifecycle-правила в MinIO |
| Open WebUI | нет | хранится, пока пользователь или администратор не удалит чаты |
| pat-service `personal_access_tokens` | нет | строки хранятся вечно; отозванные и истёкшие токены остаются со своими датами |
| pat-service `qos_events` | нет | хранится вечно; задачи очистки нет |
| QoS-ключи в Valkey | TTL в коде | сессии и цепочки 30 мин (`QOS_SESSION_TTL_SECONDS`), расход 10 мин (`QOS_SPEND_WINDOW_SECONDS`), окна MCP 2 мин, множества активных пользователей чистятся каждые 30 с |
| Prometheus (прикладной) | нет (флага `--storage.tsdb.retention.*` нет) | по умолчанию Prometheus: 15 дней, в пределах PVC на 10 Gi |
| Loki, Tempo, Prometheus из add-ons | нет (значения чарта) | см. версию чарта eg-addons в `versions.lock.env` |
| Профили агентов | нет | хранятся до `scripts/agent-profile-delete` |
| Keycloak | значения realm по умолчанию | сессии истекают по настройкам realm; учётные записи остаются |

Два следствия, которые полезно знать перед нагрузочным тестом или аудитом:

- **История Prometheus короткая.** Всё старше примерно двух недель пропадает;
  поэтому ADR фиксируют числа текстом. Экспортируйте то, что нужно сохранить.
- **Langfuse растёт без ограничений** и хранит самые чувствительные данные
  стека. Следите за заполнением PVC ClickHouse и MinIO.

## Удаление данных пользователя

Единой команды нет. Для уходящего пользователя:

1. Keycloak: отключить или удалить учётную запись (после этого его PAT перестают работать).
2. `/platform` или SQL: отозвать оставшиеся PAT (`revoked_at`); строки остаются.
3. Агенты: `scripts/agent-profile-delete <keycloak-sub|id>` удаляет поды,
   Secret и все PVC профилей ([агенты](../agents/managing.ru.md#offboarding)).
4. Open WebUI: удалить пользователя в админ-панели (удаляются его чаты).
5. Langfuse: трейсы привязаны к имени пользователя и `sub`; удалить их в
   Langfuse (UI или API) по пользователю.
6. `qos_events`: при необходимости удалить строки по `owner_subject`.

## Как задать сроки хранения

Не реализовано; куда это ляжет:

| Хранилище | Механизм |
| --- | --- |
| Prometheus | аргументы `--storage.tsdb.retention.time` / `.size` в `k8s/base/observability.yaml` |
| Langfuse | собственная настройка хранения Langfuse, если она есть в развёрнутой версии, или TTL в ClickHouse; `config/langfuse/` - зарезервированное место для его конфигурации |
| MinIO | lifecycle-правило (ILM) на bucket `langfuse` |
| `qos_events` | периодический `DELETE ... WHERE created_at < now() - interval ...` (CronJob против `pat-db`) |
| Loki | настройки хранения subchart-а Loki под ключом `loki` в `config/gateway-addons/values.yaml` (точный путь берите из values самого чарта eg-addons) |

Решение о сроках хранения дорого откатить (данные исчезают), поэтому
фиксируйте его в ADR ([как дописывать документацию](../contributing.ru.md)).

## Где это лежит

- Хранилища: `k8s/base/databases.yaml`, `k8s/base/object-storage.yaml`,
  `k8s/base/applications.yaml`, `k8s/base/observability.yaml`
- TTL в Valkey: `pat-service/internal/qos/redis.go`,
  `pat-service/cmd/pat-service/main.go`
- Учётные данные этих хранилищ: [docs/security](../../security/README.md#credential-inventory)
